# PDF-only v1 标签协议

冻结日期：2026-10-01。开发论文是仓库原有两篇 ICLR 2024 PDF，各检查前 10 页；独立论文使用 LoRA（arXiv:2106.09685），不用于调节段落间距、关联阈值或模型阈值。

目标为英文单栏主文中的普通 prose、摘要及定理/证明 prose 的真实段尾。列表项、标题、作者、算法、图表与说明、脚注、参考文献以及以独立公式结束的段落不参与短尾检查。公式前的引导句不单独算段尾。QED 外围标记不参与有效末行长度。跨页段落只在真正结束的页面标注末行。

标签先通过整页渲染和原始文字层检查确定段尾的纵向位置，再从原始字符获取位置和文本作为匹配锚点。标签制作不调用 scan_pdf、analyze_pdf、段落恢复或模型。所有选定页包括无候选页；负例段尾、豁免区域和无法确定的标签也记录。标签中的正文左右边界由模板及页面视觉确认，不使用生产代码的对齐估计。

普通正文边界为 [108,504]；摘要按实际缩进边界；绕图段落按局部正文宽度。报告两种策略：`page-2/3` 是旧整页阈值，`body-.75` 是新正文阈值。比较结构升级时采用相同 `page-2/3`，防止阈值变化掩盖错误。

空间匹配：同一页，末行 bbox 中心纵坐标相差不超过 4pt，水平范围有重叠；一对一匹配。预测重复项计误报。已标明 uncertain 的段尾单列，不能计作 TP 或确定 FN。真实短尾被模型排除、漏构段或进入 review，仍计端到端 FN；另报 review 命中的短尾数。指标分母必须列出论文数、页数、eligible 段尾、短尾数、uncertain 数。少量论文的结果是启动证据，不能声称泛化准确率。

在查看独立论文结果前固定验收要求：合成边界夹具全通过；同一整页阈值下开发集非正文误报减少且端到端 recall 不低于原版；独立论文 short-tail precision >= .85、recall >= .85，且标签短尾的自动检查覆盖率 >= .90。失败须如实记录 REVISE，不能只改指标或从分母剔除难例。
